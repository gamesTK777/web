# パル商人日記 / Pal Merchant Diary

オリジナルのターン制ダンジョン探索と街づくりゲーム。ビルド不要の静的HTML・CSS・ES modulesで動作します。

## 2026-11-08：探索袋の3段階拡張と中継帰還口

道具店の「探索袋を拡張」で、初期30個から40個（200G）・50個（500G）・60個（1,000G）へ順に拡張できます。各段階の価格で購入し、飛び級・重複購入はできません。探索中は購入不可。容量は探索で拾う品の合計個数に適用し、持ち込み道具の扱いは従来どおりです。拡張段階は消費アイテムと分けた永続強化で、敗北しても維持します。

B3・B6・B9の下り階段の左隣に「街へ」の帰還出口を追加。出口に乗り「街へ戻る · 無料」、足元を調べる、またはE / Enterで、探索品・拾得金を持って帰還できます。帰灯石は消費しません。元からある各階入口の帰還門も維持。出口は地図上のミント色と金色の枠で表示し、未探索の場所は従来どおり隠します。

セーブはversion 1を維持し、旧記録は袋の拡張0段階として読み込みます。新しい帰還出口は次の階層生成から適用し、保存済みの迷宮・探索品・街の財産を変更しません。拡張段階と中継出口を含む記録の保存・再読み込みに対応します。

検証：全145テスト成功。Windows Chromeの隔離した確認用データで3段階の購入・金額の差し引き・保存と再読み込み、B3/B6/B9で帰灯石を持たずに移動して無料帰還し、探索品と拾得金を保持することを確認。B9の出口上での保存と再開、キーボードのEnterと帰還ボタンの両方、スマートフォン幅での袋購入・横はみ出しのない表示も確認しました。iPhone Safari実機とオンライン保存の往復は今回未検証です。

## 2026-11-08：敗北ルールと「調べる」

町の方向ボタン中央にあった「調」を「調べる」に変更。主人公に最も近い施設入口または購入済み区画のメニューを開きます。距離制限はなく、移動・ターン・日付・満腹度を消費しません。

迷宮で倒れたときはレベル1・経験値0に戻り、武器・持ち物・探索品をすべて失います。装備は新しい `unarmed`（素手）になり、最大HP36・攻撃5・守備0へ再計算。救助後のHP15・満腹度60、探索金の半分持ち帰りは従来どおりです。街の所持金、株、土地、家・工房・増築段階、過去の実績・最高到達階は維持します。12ターン以上探索した場合の家賃・配当も引き続き受け取れます。

素手では主人公の剣を既存マスクで隠し、待機・歩行・攻撃を拳の表示に切り替えます。画像未読込時の代替ドット絵も素手に対応。通常武器の描画・移動・前後関係は維持します。武器を失った状態が装備強化の実績として表示されないようにし、敗北案内・持ち物の説明・操作ヘルプも新しいルールに合わせました。

通常帰還・クリア時はレベルや装備を維持します。既存のセーブを読み込んだだけでは変更せず、改修後の敗北から適用します。セーブ形式はversion 1のまま、素手の保存・再読込と武器の再購入に対応。保存サーバーは暗号化データを保管するため、サーバー変更は不要です。

## 魔物だまり

B2〜B4・B6〜B9の各階に35%の確率で最大1部屋が出現。入口・階段の部屋を避け、眠る魔物6〜8体と、回復薬・閃光の実・食料・琥珀・結晶を配置します。見える範囲の床に予兆、眠る魔物にZ、覚醒した一団に✦を表示します。

入室で一団が覚醒します。その手番は追加の魔物が動かず、長押し移動も停止。次の行動から追跡が始まります。扉を封鎖しないため、通路へ退却したり帰灯石で脱出できます。閃光の実はイベント表示からも使用可能。✦の一団を全滅させると階数×40Gを探索金へ一度だけ加算します。外から道具で倒す戦術も使えます。

開始・制圧時に光の演出と専用の効果音を追加。通常の徘徊する魔物は一団の残数には含めません。B1・B5・B10には発生せず、旧セーブの既存階には後から部屋や敵を追加しません。任意の `map.swarm` のみで覚醒・残敵ID・制圧状態を保存し、再読み込みによる報酬の重複を防ぎます。

検証：全102テスト成功。120シード×5階の生成、睡眠・入室猶予・追跡・道具での制圧・報酬の一度だけの加算・退却・帰還・旧セーブを確認。Windows Chromeの確認用記録で、入室時の長押し停止、道具使用、保存と再開、制圧、報酬を持った帰還を操作確認しました。スマートフォン幅の表示も確認。iPhone Safari実機は未検証です。

## ゲームの流れ

- 自動生成の10階層を探索。移動・攻撃・道具使用ごとに敵も行動します。
- 素材を持ち帰って売却し、武器・消耗品を購入。
- 架空の3銘柄を売買。12ターン以上の探索から帰還すると翌日に進み、株価と配当を更新。
- 最大12区画の土地に貸家・工房を建て、3段階まで増築。翌日ごとに家賃を受け取れます。
- 地下10階の灯晶の番人を倒して「暁の種」を持ち帰るとクリア。その後も探索と経営を続けられます。

## 操作

矢印 / WASD：移動・敵に向かって攻撃。Space / .：待機。E / Enter：階段。H：回復薬。F：食料。R：帰還。
画面上のボタン、主人公の上下左右をクリック・タップ、画面のスワイプにも対応。キーや方向ボタンを長押しすると、260ms後から170ms間隔で移動します。キー解除・画面離脱・ダイアログ表示で停止します。

## 保存

操作ごとにブラウザーのlocalStorage（`tk777-lantern-merchant-v1`）へ自動保存。保存画面から手動保存とJSONバックアップの書き出し・読み込みができます。
ゲーム開始後に暗号化したデータを保存サーバーへ同期し、GitHub Actionsで約15分ごとに `data/saves/<id>.json` へ暗号化バックアップを保存します。反映はGitHubの実行待ちで遅れる場合があります。別端末には保存画面の引き継ぎコードを入力します。コードは暗号鍵であり、GitHubには保存しません。書き込み権限はコードから別に導出したトークンで検証し、暗号鍵・認証トークン・認証ハッシュはアーカイブに含めません。読み込みにはサイズ制限とスキーマ検証があり、上書き前に確認します。
保存失敗時は表示して、バックアップを案内します。壊れた既存セーブは自動上書きしません。

## 2026-11-07 アニメ調キャラクターの組み込み

画像一覧で選定した「灯りの採集商」「苔玉」「夜羽」「鉱殻」「灯晶の番人」を、街・迷宮で実際に動くキャラクターとして表示します。主人公の後ろ・左・右の姿を追加制作し、4方向に対応。プロフィール・開始画面も同じ主人公画像を使います。

エンジン・当たり判定・セーブ形式は変更していません。既存データは従来どおり再開でき、街の建築区画・所持金・所持品も同じ状態を使用します。BGMの開始タイミングも画像の読込完了を待たず、開始ボタンの操作に紐付けたままです。

`music-score.mjs` に旋律・和音・音色・伴奏・リズムを分けた7つの自作曲を定義します。町の温かな旋律を活かし、迷宮5区分と魔物だまりにはそれぞれ別のテーマを作成。地下9–10階は16小節、ほかは8小節のループです。外部音源や追加のライブラリ・通信は不要です。

`music-scene.mjs` は既存のゲーム状態だけから曲を選び、セーブに項目を追加しません。魔物だまりは眠る敵の目覚めから生存する一団を全滅させるまで専用曲が続き、部屋の外へ退却しても曲は継続。制圧・階段・帰還で対応曲へ戻ります。初回読み込み、ファイル読込、オンライン復元でも階層と敵の状態を反映します。同じ2階区分内では演奏を再開始しません。曲変更時に止めるのはBGMだけで、ダメージ・制圧などの効果音は維持します。

音の設定には現在の曲名・場所・7曲一覧を追加。開始前の無音、ミュート、音量、別タブでの停止を維持します。

検証：`node --test lantern-merchant/*.test.mjs` 129件成功。全曲の音符・伴奏が有限かつ負荷上限内であること、異なる旋律・リズム、ループ境界、10階と魔物だまりの実エンジン遷移、保存再開、古い音楽タイマーの無効化、効果音との分離を確認。Windows Chromeの実際のWeb Audioで10階の曲選択、魔物だまりの開始・制圧・帰還、ミュート・解除、地下7階の保存後再読込を確認。390px相当の縦画面でも7曲一覧を表示。iPhone Safari実機は未検証です。
