# パル商人日記 / Pal Merchant Diary

オリジナルのターン制ダンジョン探索と街づくりゲーム。ビルド不要の静的HTML・CSS・ES modulesで動作します。

## ゲームの流れ

- 自動生成の5階層を探索。移動・攻撃・道具使用ごとに敵も行動します。
- 素材を持ち帰って売却し、武器・消耗品を購入。
- 架空の3銘柄を売買。12ターン以上の探索から帰還すると翌日に進み、株価と配当を更新。
- 最大12区画の土地に貸家・工房を建て、3段階まで増築。翌日ごとに家賃を受け取れます。
- 地下5階の灯晶の番人を倒して「暁の種」を持ち帰るとクリア。その後も探索と経営を続けられます。

## 操作

矢印 / WASD：移動・敵に向かって攻撃。Space / .：待機。E / Enter：階段。H：回復薬。F：食料。R：帰還。
画面上のボタン、主人公の上下左右をクリック・タップ、画面のスワイプにも対応。キーや方向ボタンを長押しすると、260ms後から170ms間隔で移動します。キー解除・画面離脱・ダイアログ表示で停止します。

## 保存

操作ごとにブラウザーのlocalStorage（`tk777-lantern-merchant-v1`）へ自動保存。保存画面から手動保存とJSONバックアップの書き出し・読み込みができます。
ゲーム開始後に暗号化したデータを保存サーバーへ同期し、GitHub Actionsで約15分ごとに `data/saves/<id>.json` へ暗号化バックアップを保存します。反映はGitHubの実行待ちで遅れる場合があります。別端末には保存画面の引き継ぎコードを入力します。コードは暗号鍵であり、GitHubには保存しません。書き込み権限はコードから別に導出したトークンで検証し、暗号鍵・認証トークン・認証ハッシュはアーカイブに含めません。読み込みにはサイズ制限とスキーマ検証があり、上書き前に確認します。
保存失敗時は表示して、バックアップを案内します。壊れた既存セーブは自動上書きしません。

## 構成と検証

- `engine.mjs`：状態遷移・迷宮生成・戦闘・経済・セーブ検証
- `renderer.mjs`：街・建物・迷宮のCanvas描画とキャラクターの合成
- `anime-characters.mjs`：アニメ調キャラクター画像の読み込み、方向切替、歩行・攻撃・待機の表示
- `app.mjs`：入力・画面・保存
- `engine.test.mjs`：19テスト。`node --test lantern-merchant/engine.test.mjs`

30シードの迷宮接続、取引整合性、帰還・敗北・5階クリア、家賃と市場の更新、セーブの往復と不正データ拒否を検証。
実ブラウザーで建築・探索・拾得・帰還・家賃・売買・リロードによる再開を確認。スマートフォン幅でタップ・スワイプを確認。iPhone Safari実機は未検証。

名称・人物・敵・画像は本作独自のものです。既存ゲームの画像・キャラクター・音楽・文章を流用していません。字体にはGoogle FontsのNoto Sans JP / Noto Serif JPを使用し、取得不可時は端末のフォントを使用します。

## 16-bit画面・音声改修

地図を横幅いっぱいに拡大。PC標準画面の表示面積は旧版のおよそ3倍、迷宮の標準タイルは72px（2〜4倍切替）です。拡大表示ボタンで画面全体を使えます。
40×48の方向別キャラクターに歩行・腕・脚・マントの動きを追加。位置補間とカメラ追従は表示だけに適用し、ゲーム進行をアニメーション完了に依存させません。
石壁・床・松明・階層の配色、敵、街の樹木・瓦・花壇を刷新。ミニマップは探索済み範囲だけを表示します。

`audio.mjs` は自作の街／迷宮BGMと16種類の効果音をWeb Audioで合成します。開始・続きからボタンを押すまでAudioContextを作成しません。ミュートと音量設定を端末に保存し、非表示タブでは停止します。既存のゲームセーブはそのまま使えます。

検証：エンジン19件、音声10件、描画3件の合計32件。既存セーブの再開、通常／拡大表示、スマホ幅のタップ・スワイプ・倍率切替、帰還時のBGM切替、ミュート・音量をブラウザーで確認。iPhone Safari実機の確認は未実施です。

開始画面の「初めから」は新しい保存先を割り当てます。以前のオンライン記録は元の引き継ぎコードで読み込めます。記録の競合時には自動上書きを止め、GitHubから復元した記録もサーバーへの再接続が済むまで自動上書きしません。

- `hero-art.mjs`: 64×72の透過スプライト、4方向・8歩行コマ・待機／攻撃。整数ピクセルでキャッシュし、補間拡大を無効化。
- `town-navigation.mjs`: 街の散歩は非保存の表示状態。18pxの移動を165msで補間し、3px間隔の衝突判定で岸辺・建物・木の幹への侵入を防止。建築・復元後は安全な位置へ戻す。
- 全景／1.5倍／2倍、主人公追従と選択施設へのカメラ。スマホ幅の初期表示は1.5倍、全景ボタンで島全体へ。施設・区画・屋根・ラベルは同じカメラ変換を使って選択でき、建築は内容と金額が見えるメニューから実行。

## 2026-11-07 アニメ調キャラクターの組み込み

画像一覧で選定した「灯りの採集商」「苔玉」「夜羽」「鉱殻」「灯晶の番人」を、街・迷宮で実際に動くキャラクターとして表示します。主人公の後ろ・左・右の姿を追加制作し、4方向に対応。プロフィール・開始画面も同じ主人公画像を使います。

`assets/characters/` に背景透過WebP8枚を配置し、合計367,878バイトに最適化。画像の先読み・デコードをまとめて1回だけ実行します。画像の読み込み待ち／失敗中は既存のコード描画へフォールバックし、ゲーム進行は画像通信に依存しません。方向別の足元位置は素材ごとに補正しています。人物画像だけ平滑補間を使い、背景ドット絵の設定は復元します。

主人公は腕・脚のある原画から下半身を分けて控えめに歩行を付け、攻撃時は向いている方向へ踏み込みます。敵には浮遊・羽ばたき・呼吸の動きが付き、ボスの結晶に淡い光が広がります。HPバーは絵の頭上へ移し、顔や結晶を隠しません。動きを減らす設定ではキャラクターの動きも抑えます。

エンジン・当たり判定・セーブ形式は変更していません。既存データは従来どおり再開でき、街の建築区画・所持金・所持品も同じ状態を使用します。BGMの開始タイミングも画像の読込完了を待たず、開始ボタンの操作に紐付けたままです。

検証：76テスト成功。画像の重複通信防止・失敗時の復帰・4方向の素材選択・接地点・歩行／攻撃・頭上HPバー・低減モーションを含みます。Windows Chromeで全8画像の読み込み、街歩き、迷宮移動・取得・帰還、再読み込み後の継続と、確認用戦闘データで攻撃を確認。390px相当の描画領域でも表示を確認。iPhone Safari実機は未検証。
