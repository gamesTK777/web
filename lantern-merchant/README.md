# 灯都の採集商 / Lantern & Ledger

オリジナルのターン制ダンジョン探索と街づくりゲーム。ビルド不要の静的HTML・CSS・ES modulesで動作します。

## ゲームの流れ

- 自動生成の5階層を探索。移動・攻撃・道具使用ごとに敵も行動します。
- 素材を持ち帰って売却し、武器・消耗品を購入。
- 架空の3銘柄を売買。12ターン以上の探索から帰還すると翌日に進み、株価と配当を更新。
- 最大12区画の土地に貸家・工房を建て、3段階まで増築。翌日ごとに家賃を受け取れます。
- 地下5階の灯晶の番人を倒して「暁の種」を持ち帰るとクリア。その後も探索と経営を続けられます。

## 操作

矢印 / WASD：移動・敵に向かって攻撃。Space / .：待機。E / Enter：階段。H：回復薬。F：食料。R：帰還。
画面上のボタン、主人公の上下左右をクリック・タップ、画面のスワイプにも対応。押しっぱなしのキーリピートは無効です。

## 保存

操作ごとにブラウザーのlocalStorage（`tk777-lantern-merchant-v1`）へ自動保存。保存画面から手動保存とJSONバックアップの書き出し・読み込みができます。
クラウド同期はありません。別端末への移行はバックアップファイルで行います。読み込みにはサイズ制限とスキーマ検証があり、上書き前に確認します。
保存失敗時は表示して、バックアップを案内します。壊れた既存セーブは自動上書きしません。

## 構成と検証

- `engine.mjs`：状態遷移・迷宮生成・戦闘・経済・セーブ検証
- `renderer.mjs`：オリジナルのCanvasピクセル画、町・建物・迷宮・キャラクター
- `app.mjs`：入力・画面・保存
- `engine.test.mjs`：19テスト。`node --test lantern-merchant/engine.test.mjs`

30シードの迷宮接続、取引整合性、帰還・敗北・5階クリア、家賃と市場の更新、セーブの往復と不正データ拒否を検証。
実ブラウザーで建築・探索・拾得・帰還・家賃・売買・リロードによる再開を確認。スマートフォン幅でタップ・スワイプを確認。iPhone Safari実機は未検証。

名称・人物・敵・画像は本作独自のものです。既存ゲームの画像・キャラクター・音楽・文章を流用していません。字体にはGoogle FontsのNoto Sans JP / Noto Serif JPを使用し、取得不可時は端末のフォントを使用します。
