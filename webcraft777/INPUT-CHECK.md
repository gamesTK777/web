# ウェブクラフト777の視点操作

## 更新前に確認したこと

2026年11月21日、開いていたChromeのタブとGitHub Pagesの配信内容が同じ旧ビルド（`index-BCVKFrem.js`）であることを確認しました。以前の入力改修は作業ブランチにあり、当時の公開版は旧入力処理を使っていました。

別プロファイルのWindows版Chrome 157.0.8103.80では、高速な左右・上下の切り返しだけで停止は再現しませんでした。以下は入力やブラウザーの応答を変えた試験で確認しました。

- 不正な視点移動値を1回入れるとカメラの角度が無効になり、描画が動いている一方で、その後の手動保存が拒否されました。
- マウスを固定するブラウザー応答を約1.1秒遅延させると、先にドラッグ操作へ切り替わったあと、遅れて固定されました。
- 小刻みな縦スクロール、横優勢のスクロール、ピンチに相当する通知がそれぞれホットバーを動かしました。

MacBook Neo本体とそのトラックパッドは、このWindowsの検証環境から操作できません。報告された現象と上記の再現条件の関係は、元の端末では未確認です。

## 修正版の確認

Windows版Chromeで左右・上下の高速切り返し、マウス固定の解除と再取得、遅延許可、ドラッグ操作、タブ切り替え、描画コンテキストの復旧を確認しました。約1.1秒遅れた許可は解除され、ドラッグでの操作を続けられました。小さいスクロール、横方向のスクロール、ピンチに相当する通知ではホットバーが移動せず、意図した通常の縦スクロールでは移動しました。無効な移動値を入力しても最後の正常な視点を保ち、同じワールド、建築差分と所持品を保存できました。自動テストは60件すべて成功しています。

## 操作を復旧する

1. プレイ中はEscまたは画面の「一時停止」を押します。Macの初期設定では「再開」でドラッグ操作に戻ります。
2. トラックパッドを押したまま指を動かすと見回せます。ブロックには画面上の「採掘」「設置」を使います。矢印キーでも見回せます。
3. クリックせず見回す操作を試すときは、一時停止の「視点を固定してプレイ」を選びます。ブラウザーが固定を解除した場合は、入力を止めてドラッグ操作で再開できる案内を表示します。
4. 動きが止まったときは、一時停止の「入力の診断・復旧」を開きます。「入力をリセット」で押下状態を解除し、「診断をファイルに書き出す」で最近の入力方式、角度、ブラウザーの通知をJSONに記録できます。記録は端末内で処理します。

元のMacで再検証する場合は、Chromeの独立タブでドラッグと固定視点を両方試し、左右・上下に連続して切り返します。起きた時のChrome・macOSの版、移動や一時停止に反応するか、直近の診断記録があれば、原因の絞り込みに使えます。
