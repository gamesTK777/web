# 初回描画と画質設定の測定

2026年11月20日、Windows の Chrome 157 ヘッドレス、GeForce RTX 5080（ANGLE / D3D11）で計測。各実行は独立したブラウザープロファイルで順番に行った。

## 起動時の準備

同じ旧版ワールド「湖畔の小屋」を読み込み、出現地点で比較した。画面は1920×1080、内部描画は両版とも1460×821、距離3チャンク、倍率100%、影なし。各版1回の測定値で、単位はミリ秒。[旧版の記録](tests/results/quality/before-startup.json) ／ [改修版の記録](tests/results/quality/after-startup.json)

| 処理 | 旧版 | 改修版 |
| --- | ---: | ---: |
| 地形の生成と建築・採掘差分の復元 | 58.7 | 52.6 |
| 描画器・素材の準備 | 39.3 | 58.7 |
| 出現地点周辺のチャンク形状を全て生成 | 82.4 | 77.1 |
| シェーダー事前準備の完了待ち | 26.8 | 36.6 |
| 準備後の初回描画呼び出しと完了待ち | 27.7 | 26.9 |
| 上記5項目の合計 | 234.9 | 251.9 |

シェーダープログラム数は7から10に増えた。両版で並列コンパイル拡張を利用できた。開発用の `/tests/startup.html` はチャンク生成、シェーダー準備、最初の描画を順に実行する。ゲーム本編はチャンク生成を複数フレームに分けるため、起動ボタンを押してから遊べるまでの時間は別途扱う。ネットワーク取得、GPU単体の実行時間、ドライバーのキャッシュ状態は未測定。

## 水辺で設定を1項目ずつ切り替え

改修版の標準画質を基準に、同じシード・座標・時刻で比較した。内部描画は1920×1080。各設定でチャンク生成を終え、最初の4フレームを除く48フレームを採取した。時間は JavaScript から描画を要求し、WebGL の完了待ちが戻るまでの経過時間。画面更新の待ち時間を含む実プレイのFPSは別の測定表に掲載している。[画質別の記録](tests/results/quality/effects.json) ／ [実プレイ描画の比較](QUALITY-RENDER.md)

| 設定 | 中央値（ms） | 95パーセンタイル（ms） | 描画回数 | 三角形数 |
| --- | ---: | ---: | ---: | ---: |
| 標準 | 0.3 | 0.5 | 59 | 46,574 |
| 影をオフ | 0.3 | 0.5 | 59 | 46,574 |
| 草花をオフ | 0.3 | 0.4 | 59 | 44,982 |
| 水面・葉・手元の追加演出をオフ | 0.3 | 0.4 | 59 | 46,574 |

この水辺では草花をオフにすると三角形が1,592枚減った。中央値はどの設定も0.3msで、表示桁と採取回数の範囲では時間差を識別できなかった。再実行には開発サーバーで `/tests/effects.html` を開く。
