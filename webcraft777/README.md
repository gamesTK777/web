# ウェブクラフト777

湖と森が広がる有限のワールドを歩き、採掘した素材で家を建てる、TK777 ARCADE の一人称ボクセルゲームです。PC 版 Chrome・Edge、キーボードとマウス、WebGL 2 対応のグラフィックス環境を使用します。音とテクスチャはブラウザーで生成し、タイトル画像・アイコン・描画ライブラリは配信物に同梱しています。

## すぐに遊ぶ

**Windows では、Node.js 22.12 以降または 24 系を用意し、展開したフォルダーの `Run-WebCraft.cmd` をダブルクリックします。** 既定のブラウザーにゲームが開きます。同梱の公開用ビルドを使うので、この手順で npm パッケージをインストールする必要はありません。

コマンドからは、この README のあるフォルダーで次を実行します。

```sh
node preview.mjs
```

[ローカルのゲーム画面](http://127.0.0.1:8782/webcraft777/play/) を開いてください。遊び終わったら保存を確認し、サーバーを起動した端末で Ctrl+C を押します。ポートを変更する場合は環境変数 `WEBCRAFT_PORT` を設定します。次回も同じブラウザー・アドレス・ポートで開くと同じセーブを利用できます。

「新しく始める」で名前、シード、モードを選びます。シードが同じなら地形や木の形も同じです。「プレイ開始」で視点操作と音が有効になります。WebGL 2 のエラーが出た場合は、Chrome または Edge の設定でグラフィックス アクセラレーションを有効にしてブラウザーを再起動してください。

## 遊び方

| 操作 | 効果 |
| --- | --- |
| W・A・S・D、マウス移動 | 前後左右の移動、見回す |
| Space、Shift | ジャンプ、水中で浮上、Shift を押しながら移動でダッシュ |
| 左クリック／長押し | 照準で囲まれたブロックを掘る。探索モードでは採掘の進行を表示 |
| 右クリック | 照準を合わせた面に選択中の建材を1個置く |
| 数字1〜9、ホイール | ホットバーの選択を切り替える |
| E | 持ち物・クラフトを開閉。持ち物から選択中のホットバー枠へ登録 |
| F、飛行中の Space・Ctrl | クリエイティブの飛行切り替え、上昇・下降 |
| Esc | 視点を解放して一時停止。再開、保存、設定、操作説明を選べる |
| F3 | FPS、描画回数、表示チャンク数、現在の座標を表示 |

編集できるのは視線が届く5ブロック以内です。手前のブロックが奥を隠し、体と重なる場所には建材を置けません。足元を掘ると落下します。埋め込み画面でマウスを固定できないときはドラッグで見回し、画面の「採掘」「設置」ボタンを使います。「ドラッグ操作でプレイ」を手動で選ぶこともできます。独立したタブで開けば「再開」から視点の固定を再度試せます。

### 探索モードで最初の家を建てる

1. 開始地点の近くの木から**原木を2個**集めます。E でクラフトを開き、木材を計8個にします。
2. 木材2個から棒4本を作ります。残る木材6個と棒4本で、木のツルハシと木の斧を1本ずつ作れます。E で使いたい道具をホットバーに登録してください。
3. 岸辺の石をツルハシで掘って丸石を集めます。石レンガを土台にし、斧で切った原木から壁と屋根の木材を作ります。入口に2ブロック分の高さを残すと歩いて出入りできます。
4. 石炭鉱石から取れる石炭で灯晶ブロックや窓用の朝霧ガラスを作ります。夕方には玄関の灯りを確かめてください。

| 材料 | 完成品 |
| --- | --- |
| 原木1 | 木材4 |
| 木材2 | 棒4 |
| 木材3＋棒2 | 木のツルハシ1、または木の斧1 |
| 丸石3＋棒2 | 石のツルハシ1、または石の斧1 |
| 丸石4 | 石レンガ4 |
| 砂3＋石炭1 | 朝霧ガラス4 |
| 木材2＋石炭1 | 灯晶ブロック2 |

所持品は27枠で、通常の素材は1枠64個までです。道具は1本ごとに1枠を使い、木製は耐久36、石製は耐久90です。道具を持って採掘に成功するたびに耐久が1減ります。所持品が満杯なら採掘を止め、その場に素材を残します。

**クリエイティブモード**では、E から12種類の建材を選んでホットバーに登録できます。数量は無制限で、素早い採掘と飛行を使って建築できます。

## セーブとバックアップ

- ワールドごとに固有 ID を発行し、同じ名前でも別のワールドとして保存します。ゲーム内の進行は IndexedDB、タイトルでの設定は同じブラウザーのローカルストレージに記録します。
- ワールドを開いている間は前面で25秒ごとに自動保存します。ポーズ中の「手動保存」やタイトルへ戻る操作でも保存します。「保存済み」の表示で書き込み完了を確認できます。
- 保存対象はワールド名・ID・シード・モード、位置と向き、飛行状態、所持数、道具の耐久、ホットバーと選択枠、建築・採掘の差分、昼夜、設定などです。掘ったブロックは空気として記録します。保存形式と地形生成方式はともにバージョン1です。
- 別のPCへ移るときやサイトデータを削除する前は、ポーズ画面の「ファイルへ書き出す」、または「つづきから」の一覧にある「書き出す」で JSON を保管します。復元側では「つづきから」→「ファイルを読み込む」でそのファイルを選びます。
- 付属の [湖畔の小屋のセーブ](examples/lakeside.json) を「ファイルを読み込む」で選ぶと、木材・ガラス・石レンガで建てた小屋を歩いて見学し、続きを遊べます。
- 読み込みは1ファイル128 MiBまでで、形式、バージョン、所持品、設定、地形差分を検証します。同じ ID のワールドが存在する場合は、置き換えを確認します。別タブからの保存が先行した場合は新しい記録を保護します。
- ブラウザーのデータ削除やプライベートウィンドウの終了では、端末内のセーブが消える場合があります。ローカル起動と GitHub Pages は別の保存領域になるため、データ移行には書き出した JSON を使います。

## 開発・ビルド・配置

推奨開発環境は Node.js 22.12 以降または 24 系と npm です。以下は `webcraft777` フォルダーで実行します。

```sh
npm ci
npm run dev
```

端末に表示されたローカルアドレスを開きます。テスト・本番ビルド・そのプレビューはそれぞれ次のコマンドです。

```sh
npm test
npm run build
npm run preview
```

ビルドは型チェック後に `play/` を生成します。TK777 ARCADE のリポジトリでは、トップの `index.html` が `webcraft777/play/index.html` を開きます。静的ホストには `webcraft777/play/` の中身を階層ごと配置してください。Vite の `base: './'` により JavaScript・CSS・画像を相対パスで読み込みます。ゲームの配信に npm・専用ゲームサーバー・APIキーは不要です。ファイルのダブルクリックではなく、HTTP または HTTPS で開いてください。

配布 ZIP の直下には `portal-entry.patch` も同梱しています。別の TK777 ARCADE 作業コピーへ移すときに、既存トップページへ追加するカードの差分を確認できます。

| 項目 | 固定バージョン |
| --- | --- |
| Three.js、@types/three | 0.180.0 |
| TypeScript | 5.9.3 |
| Vite | 7.3.1 |
| tsx | 4.21.0 |
| fake-indexeddb（テスト用） | 6.2.4 |

`package-lock.json` に推移依存を含むバージョンを固定しています。Three.js の MIT ライセンスは [public/THREE-LICENSE.txt](public/THREE-LICENSE.txt) に同梱し、ビルド時に配信物へコピーします。

### 主なソース

| ファイル | 担当 |

## 検証と制限

自動テスト31件が成功しました。座標とチャンクの境界、共有面の除去・再生成、衝突、採掘と設置の距離、所持品が満杯のときの取り消し、制作数と耐久値、シードからの再現、建物と穴の復元、保存の競合、フォーカスを失った後の入力解除を対象にしています。

開発サーバーの `/tests/scenario.html` では「3場面を準備する」で開始地点・建築中・夕方を表示できます。通常の編集判定を通して小屋に208ブロックを置き、チャンク境界をまたぐ建物と掘った穴を、ゲームとは別の IndexedDB に書き出して読み込みます。同じ小屋をゲームで開けるバックアップも取得できます。`/tests/soak.html` では描画距離3、解像度倍率1、影なしで10分間周遊し、1分ごとのFPS・描画回数・チャンク数・形状数を表示します。正しく測るため、起動後はこのタブを前面に置いてください。実際のブラウザーでの確認範囲・計測環境・実測結果は [QA.md](QA.md) にまとめています。

ワールドは有限で、最下層の岩盤は破壊できません。水は静的で、灯りの描画はプレイヤー付近を優先します。マルチプレイ、敵、空腹・死亡ペナルティ、農業、電気回路、スマートフォン向けタッチ操作は実装範囲外です。動作速度は解像度・GPU・ブラウザーに左右されます。重い場合は設定で描画距離と解像度倍率を下げ、影をオフにします。
