# ウェブクラフト777

湖畔に拠点を作り、森や岩窟で見つけた素材を持ち帰って家を育てる、TK777 ARCADE のボクセルゲームです。一人称のオリジナルモードと、キャラクターを斜め上から見渡すキッズモードを使えます。探索モードには大樹・岩窟・遺跡があり、クリエイティブでは飛行と取り消しを使って自由に建築できます。WebGL 2対応のブラウザーで、キーボードとマウスまたはタッチ操作で遊べます。テクスチャと音はゲーム内で生成し、タイトルの風景とライブラリを同梱しています。

## すぐに遊ぶ

TK777 ARCADEの[公開版をブラウザーで開く](https://gamestk777.github.io/web/webcraft777/play/index.html)。以前と同じブラウザーで「つづきから」を選ぶと、保存してある家や持ち物を引き継げます。

**Windows では、Node.js 22.12 以降または 24 系を用意し、展開したフォルダーの `Run-WebCraft.cmd` をダブルクリックします。** 既定のブラウザーにゲームが開きます。同梱の公開用ビルドを使うので、この手順で npm パッケージをインストールする必要はありません。

コマンドからは、この README のあるフォルダーで次を実行します。

```sh
node preview.mjs
```

[ローカルのゲーム画面](http://127.0.0.1:8782/webcraft777/play/) を開いてください。遊び終わったら保存を確認し、サーバーを起動した端末で Ctrl+C を押します。ポートを変更する場合は環境変数 `WEBCRAFT_PORT` を設定します。次回も同じブラウザー・アドレス・ポートで開くと同じセーブを利用できます。

「新しく始める」で名前、シード、モードを選びます。シードが同じなら地形や木の形も同じです。「プレイ開始」で視点操作と音が有効になります。WebGL 2 のエラーが出た場合は、Chrome または Edge の設定でグラフィックス アクセラレーションを有効にしてブラウザーを再起動してください。

## マルチプレイ

タイトルの「マルチプレイ」から、クリエイティブ・探索・鬼ごっこのルームを作ります。同じ部屋で遊ぶ人に8文字のルームコード、または一時停止画面の「招待リンクをコピー」で作ったリンクを送ります。参加者はニックネームを入力して入室します。最大6人で、相手の姿と移動が同じワールドに反映されます。PCの操作、スマートフォンのスティック、オリジナルモードとキッズモードを個別に選べます。

ルームを作る人は「森と湖」「まっさらな平地」「湖だけ」から、サムネイルを見ながらステージを選べます。招待された人には同じステージが読み込まれます。平地や湖で探索を始めると、道具や作業台を作るための原木と石炭が各参加者に支給されます。

探索ルームでは、採掘した人が素材を受け取り、自分の持ち物で道具や建材を作れます。作業台は全員で使えます。同じタブから同じ名前で入り直すと、持ち物と探索の記録を引き継げます。チェストはひとり用で使えます。部屋の建築は通信サービスに保存され、最後の利用からおよそ24時間は同じコードで参加し直せます。ひとり用のセーブはブラウザーに保存されます。

鬼ごっこは2人から遊べます。開始時と、体がぶつかって鬼が交代するたびに、全員の画面に20秒のカウントダウンが出ます。その間、鬼はその場で動けなくなり、逃げ役は移動して隠れられます。ダッシュ速度は鬼と逃げ役で10対7です。頭上の名前は画面内で姿が見える相手にだけ表示します。Mキーか画面の「地図」で半透明マップを開くと、追いかけっこ中に32×32ブロックの区画ごとの相手の人数を確認できます。

鬼ごっことドロケイでは、移動しながらShiftキーかタッチ画面の「ダッシュ」を押し続けると加速します。スタミナ満タンから約4秒間ダッシュでき、歩くか止まって約1.2秒経つとゲージが回復し始めます。使い切ったときは、回復してからダッシュ入力をいったん放して押し直せます。CPUにも同じ速度とスタミナのルールが適用されます。

新しい鬼ごっこルームを作るときに、制限時間を1・3・5・10・15分から選べます。初期設定は5分です。制限時間は追いかけっこの間にだけ進みます。時間切れになった瞬間の鬼が敗北し、逃げ切った参加者は全員勝利です。隠れる時間が始まる前に参加者全員が「プレイ開始」を押せるようにしてください。続けて対戦するには新しいルームを作ります。

鬼ごっこのルームを作るときは「学校」も選べます。2階建ての校舎で、教室の机や棚の陰に隠れたり、廊下と両端の階段を使って逃げたりできます。「地図」またはMキーを押すと自分がいる階の見取り図が開き、同じ階の相手は大まかな区画ごとの人数で、別の階の相手は人数だけで表示します。

まっさらな平地と学校の鬼ごっこでは、ルーム作成時にCPUを0〜4人加えられます。プレイヤー1人とCPUでも対戦でき、招待した仲間と合わせて最大6人です。

### ドロケイ

ルーム作成で「ドロケイ」を選び、「みどりの大公園」または「渋谷スクランブル」からステージを選びます。2〜6人で遊べます。ケイとドロは歩行・ダッシュともに同じ速度です。開始時は20秒の隠れる時間があり、ケイはその場で待機します。追跡が始まると、ケイに触れられたドロは牢屋へ移動します。逃げているドロが牢屋前の救出区画に入ると捕まった仲間を全員救出できます。全員を確保すればケイの勝ち、制限時間までドロが逃げ切ればドロの勝ちです。Mキーか「地図」で牢屋の位置を確認できます。

どちらのステージでもルーム作成時にCPUを0〜4人追加できます。CPUを1人以上入れると、人間のプレイヤー1人でも開始できます。CPUが2人以上なら両チームに入り、ケイのCPUは追跡と確保、ドロのCPUは逃走と仲間の救出を行います。人間とCPUを合わせて最大6人です。

大公園では、階段から大滑り台の坂に乗るとそのまま滑れます。アスレチックの高台や橋からも逃げ道を選べます。ブランコや4人乗りのシーソーに近づき、Vキーまたは画面のボタンで乗り降りできます。着席中はW/Sキーやスティックの前後入力でこげます。

ローカルで2つのブラウザーから試すには、`node preview.mjs --online` で起動し、表示されたローカルURLを両方で開きます。公開版の通信サービスとローカルのプレビューは別のルームを使用します。

## ステージと生き物

ひとり用の「新しく始める」では、ゲーム内の風景を撮影したサムネイルから「森と湖」「まっさらな平地」「湖だけ」を選べます。森と湖は探索・クリエイティブ、平地と湖だけはクリエイティブで遊びます。平地は遊具や大きな建築を自由に試せます。湖だけは砂浜から水に入れます。

ひとり用の森と湖では、地上に住民4人、羊4頭、牛4頭がいます。照準を合わせて V、右クリック、またはタップで話しかけられます。森と湖や湖だけの水中には、ヒスイフィッシュ、アンバーフィッシュ、サメがいます。サメに近づくと水中で襲われるため、照準を合わせて左クリック、X、または画面の「攻撃」を使います。体力がなくなると持ち物を持ったまま岸に戻ります。サメを倒した結果はそのワールドに残ります。

## 西部の町

ひとり用の「新しく始める」で「西部の町」を選べます。探索では林と鉱山で素材を集め、町の作業場で道具を作れます。クリエイティブでは「建材と道具」から道具を直接選べます。町の外れに家を建てられる空き区画が4つあります。

盗賊やギャングが町を襲うと、保安官が応戦します。襲撃や火事が収まると、住民が町の建物を修理します。自分の家は自分で直します。体力がなくなると、持ち物を引き継いで町の入口に戻ります。

リボルバー、弓、火矢、たいまつをホットバーに入れ、左クリック、X、または画面の「使う」で使用します。探索ではリボルバーに弾、弓に火矢を使います。火は木や葉に燃え広がり、石の建材は残ります。炎に照準を合わせてVを押すと消火できます。焼け跡や燃えている場所はワールドと一緒に保存されます。

## ジャンプ台と滑り台

ジャンプ台（小・中・大）は、上に乗ると約3・6・10ブロックの高さまで跳び上がります。滑り台は、R または画面の「向き」で坂の下り方向を決めて設置します。下りたい方向に1マスずつ、段も1ブロックずつ低くして坂をつなぐと、好きな高さから滑れます。高い方から乗ってください。

クリエイティブでは持ち物の建材一覧、探索ではクラフトから使えます。新しい平地と湖だけのワールドには、ジャンプ台と滑り台が最初からホットバーにあります。共同建築ルームでも持ち物から選んで設置できます。

## 遊び方

| 操作 | 効果 |
| --- | --- |
| W・A・S・D、マウス移動 | 前後左右の移動、見回す |
| K、画面上部のモードボタン | プレイ中にオリジナルモードとキッズモードを切り替える |
| Space、Shift | ジャンプ、水中で浮上、Shift を押しながら移動でダッシュ |
| 左クリック／長押し | 照準で囲まれたブロックを掘る。探索モードでは採掘の進行を表示 |
| 右クリック | 緑の角枠に建材を設置。赤い×は設置不可。作業台・チェストを狙ったときは開く |
| C または Ctrl 長押し | しゃがんで低い坑道へ。接地時は足場の端で踏みとどまる。設備の隣に建材を置く場合も使う |
| Q またはホイールクリック | 見ている建材を選ぶ。探索モードでは手持ちの建材を選択 |
| R | 原木の向きを縦・東西・南北に切り替える。設置予定位置の木口で確認できる |
| Ctrl＋Z | クリエイティブで直近20件まで戻す。作業台・チェストは対象外。復元先が体に重なる場合は少し離れる |
| V | 照準を合わせた作業台・チェストを開く |
| B、G | Bで現在地を拠点に登録。Gで探索目標の表示を切り替える |
| 数字1〜9、ホイール | ホットバーの選択を切り替える |
| E | 持ち物・クラフトを開閉。持ち物から選択中のホットバー枠へ登録 |
| F、飛行中の Space・Ctrl | クリエイティブの飛行切り替え、上昇・下降 |
| Esc | 視点を解放して一時停止。再開、保存、設定、操作説明を選べる |
| F3 | FPS、描画・三角形・チャンク数、更新待ちと更新時間、GPU上の形状・テクスチャの個数、現在座標を表示 |

編集できるのは視線が届く5ブロック以内です。手前のブロックが奥を隠し、体と重なる場所には建材を置けません。足元を掘ると落下します。

キッズモードでは、キャラクターと周囲を斜め上から眺めながら移動・採掘・建築を続けられます。照準はキャラクターが狙っている面に重なり、狭い坑道ではカメラが近づきます。プレイ中に切り替えると現在地や持ち物をそのまま引き継ぎ、最後に選んだ視点をこのブラウザーに記憶します。

スマートフォンやタブレットでは、左下のスティックを動かしたい方向へドラッグし、指を離すと止まります。右側の空いている場所をドラッグすると見回せます。緑の設置枠が出た状態で景色を短くタップするか、「設置」ボタンを押すと、選択中のブロックを置けます。移動中も別の指で視点変更、ジャンプ、採掘ができます。「しゃがむ」「採掘」は長押しします。クリエイティブでは「飛行」を押すと、上昇・下降ボタンで高さを変えられます。

PCでも、プレイ開始前または一時停止画面の「タブレットモードでプレイ」から、移動スティックと画面上のボタンを表示できます。タッチパネル搭載PCでは画面に触れて操作でき、キーボードやマウスも併用できます。操作方法はブラウザーに記憶され、オリジナルモード・キッズモードのどちらでも使えます。操作方法を切り替えるには、一時停止画面で「視点を固定してプレイ」または「ドラッグ操作でプレイ」を選びます。

Macでは初期設定でドラッグ操作が始まります。トラックパッドを押したまま指を動かして見回し、画面の「採掘」「設置」を使います。マウスを固定して見回す方式は、一時停止の「視点を固定してプレイ」から選べます。選んだ操作方式はこのブラウザーに記録されます。マウスの固定が途中で外れた場合や無効な角度を受け取った場合は、一時停止からドラッグ操作で再開できます。

「入力の診断・復旧」では、最近の操作と一時停止の理由を確認できます。「入力をリセット」で押下状態を解除します。「診断をファイルに書き出す」は、この端末にJSONをダウンロードします。操作の切り分けとMacBook Neoでの確認手順は[視点操作の確認記録](INPUT-CHECK.md)を参照してください。

### 湖畔の家と最初の遠征

1. 開始地点の近くの木から**原木を2個**集めます。E でクラフトを開き、木材を計8個にします。
2. 木材2個から棒4本を作ります。残る木材6個と棒4本で、木のツルハシと木の斧を1本ずつ作れます。E で使いたい道具をホットバーに登録してください。
3. もう少し原木を採り、作業台を床に置きます。右クリックで開くと石の道具、石レンガ、ガラスを作れます。荷物が増えたらチェストへ。所持品とチェストには分割・整理・まとめて移動があり、道具ごとの耐久も引き継ぎます。中身のあるチェストは先に空にしてください。
4. Bで家の位置を記録します。石炭鉱石を掘り、灯晶ブロックを準備。灯りを持って「潮晶の岩窟」の坑道へ入ると探索目標が進みます。中の青緑の鉱脈を木か石のツルハシで掘ってください。
5. 拠点の矢印をたどって帰り、作業台で青磁のランタンか象眼タイルを作ります。拠点から18ブロック以内に飾ると最後の目標を達成します。風待ちの大樹からは柱用の原木を、潮見の回廊からは床飾りを持ち帰れます。

建築も楽しむ最初の約30分の遊び方として、最初の家に「梁のある玄関」「チェストを置ける工房」「湖を眺める窓辺」を一つずつ増やしてみてください。目標に制限時間はありません。持ち物画面の「まとめて」で、材料と空き枠に応じた回数を一度に制作できます。

| 材料 | 完成品 |
| --- | --- |
| 原木1 | 木材4 |
| 木材2 | 棒4 |
| 木材3＋棒2 | 木のツルハシ1、または木の斧1 |
| 丸石3＋棒2 | 石のツルハシ1、または石の斧1 |
| 丸石4 | 石レンガ4 |
| 砂3＋石炭1 | 朝霧ガラス4 |
| 木材2＋石炭1 | 灯晶ブロック2 |
| 木材4 ／ 木材6 | 作業台1 ／ 収納チェスト1 |
| 潮晶のかけら1＋灯晶ブロック1 | 青磁のランタン2（作業台） |
| 潮晶のかけら1＋丸石4 | 潮晶の象眼タイル8（作業台） |
| 朝霧ガラス2＋石炭1 | 潮晶のかけら2（旧地形の作業台専用） |

所持品もチェストも27枠で、通常の素材は1枠64個までです。道具は1本ごとに1枠を使い、木製は耐久36、石製は耐久90です。道具を持って採掘に成功するたびに耐久が1減ります。所持品が満杯なら採掘を止め、その場に素材を残します。クリエイティブのチェストでは「建材を補充」から所持品に1個、Shift＋クリックで64個を用意して預けられます。

**クリエイティブモード**では、Eから建材・設備・照明を選び、9枠に登録できます。数量は無制限です。取り消し履歴は現在のワールドを開いている間だけ保持します。

### 画質と音

設定の「低」「標準」「高」で距離、内部解像度、影、草花、追加演出をまとめて切り替えられます。個別調整も可能です。採掘のひびと設置可能・不可の表示は低画質でも使えます。暗い場所では周囲の灯りを最大4個描画します。主音量・効果音・環境音、上下反転、歩行時の揺れ、ダッシュ時の視野変化を独立して調整できます。森では鳥と風、湖岸では水音、坑道では滴の音に切り替わります。

## セーブとバックアップ

- ワールドごとに固有 ID を発行し、同じ名前でも別のワールドとして保存します。ゲーム内の進行は IndexedDB、タイトルでの設定は同じブラウザーのローカルストレージに記録します。
- ワールドを開いている間は前面で25秒ごとに自動保存します。ポーズ中の「手動保存」やタイトルへ戻る操作でも保存します。「保存済み」の表示で書き込み完了を確認できます。
- 保存形式2に、位置・向き・飛行・しゃがみ、所持品と耐久、ホットバー、建築と採掘、昼夜と設定、チェストの中身、作業台の制作回数、原木の軸、拠点と探索目標を記録します。回収済みの鉱石は空気として残ります。
- 新規ワールドの地形生成は2です。旧ワールドは保存形式だけを更新し、地形生成1を使い続けます。旧ワールドには作業台で朝霧ガラスと石炭を潮晶に加工する専用レシピがあります。旧地形での探索目標は岩天井のある通路に灯りを持ち込むと進みます。
- 旧版のブラウザーセーブを最初に更新するとき、元の記録を同じ保存処理で保管します。「つづきから」→「旧版の原本」でJSONを取得できます。旧版ファイルを読み込んだ場合も原本を保管します。移行エラー時は一覧に戻って原本を書き出し、保管していたバックアップを選んでください。
- 別のPCへ移るときやサイトデータを削除する前は、ポーズ画面の「ファイルへ書き出す」、または「つづきから」の一覧にある「書き出す」で JSON を保管します。復元側では「つづきから」→「ファイルを読み込む」でそのファイルを選びます。
- 付属の [湖畔の小屋のセーブ](examples/lakeside.json) を「ファイルを読み込む」で選ぶと、木材・ガラス・石レンガで建てた小屋を歩いて見学し、続きを遊べます。
- 読み込みは1ファイル128 MiBまでで、形式、バージョン、所持品、設定、地形差分を検証します。同じ ID のワールドが存在する場合は、置き換えを確認します。別タブからの保存が先行した場合は新しい記録を保護します。
- ブラウザーのデータ削除やプライベートウィンドウの終了では、端末内のセーブが消える場合があります。ローカル起動と GitHub Pages は別の保存領域になるため、データ移行には書き出した JSON を使います。

## 開発・ビルド・配置

推奨開発環境は Node.js 22.12 以降または 24 系と npm です。以下は `webcraft777` フォルダーで実行します。

```sh
npm ci
npm run dev
```

端末に表示されたローカルアドレスを開きます。テスト・本番ビルド・そのプレビューはそれぞれ次のコマンドです。

```sh
npm test
npm run build
npm run preview
```

## 検証と制限

公開用ビルドの操作確認と計測は分けて行いました。同じ条件で再計測したい場合は、開発サーバーで `/tests/comparison.html?shadows=1` を開いて「3場面を計測」または「同じ地域を周回」を選び、計測中はタブを前面にしてください。完了後に計測結果をJSONで保存できます。初期表示の内訳は `/tests/startup.html`、画質項目別の測定は `/tests/effects.html` で再現できます。

今回の検証は[機能とセーブの確認記録](QUALITY.md)と[景観比較・性能の測定結果](QUALITY-RENDER.md)にまとめています。自動テストは旧地形の照合、セーブ移行、収納・制作の数量、壁・天井・足場の端、チャンク角の陰影、取り消し、探索経路などを対象にしています。開発サーバーの `/tests/journey.html` で新規ワールドの探索・帰還・保存を、`/tests/comparison.html` で旧地形における4場面と性能比較を再現できます。

開発サーバーの `/tests/scenario.html` では「3場面を準備する」で開始地点・建築中・夕方を表示できます。通常の編集判定を通して小屋に208ブロックを置き、チャンク境界をまたぐ建物と掘った穴を、ゲームとは別の IndexedDB に書き出して読み込みます。同じ小屋をゲームで開けるバックアップも取得できます。`/tests/soak.html` では描画距離3、解像度倍率1、影なしで10分間周遊し、1分ごとのFPS・描画回数・チャンク数・形状数を表示します。正しく測るため、起動後はこのタブを前面に置いてください。初版での測定環境と結果を[旧検証記録](QA.md)に保管しています。

ワールドは有限で、最下層の岩盤は破壊できません。水は静的で、灯りの描画はプレイヤー付近を優先します。空腹・死亡ペナルティ、農業、電気回路は実装範囲外です。動作速度は解像度・GPU・ブラウザーに左右されます。重い場合は設定で描画距離と解像度倍率を下げ、影をオフにします。
