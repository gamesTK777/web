HOW TO SHIFT

ひとつ先のプレイへ。

横一列をブロックで埋めると消去。上まで積み上がるとゲーム終了です。ARCADEでは10ラインごとにレベルと落下速度が上がります。

左右移動← → / A D右回転 / 左回転↑・X / Zソフト / ハードドロップ↓・S / Spaceホールド（1設置につき1回）C / Shiftスキル / 一時停止1 2 3 / P・Esc

スマホでは盤面またはその下の操作エリアを使います。タップで右回転、左右スワイプで移動。指を止めると横移動も止まります。素早い下フリックで一気に落下、ゆっくり下にドラッグするとソフトドロップ、上フリックでホールド。着地点の輪郭が落下位置の目印です。補助ボタンは下の設定で表示できます（1回押すごとに1操作）。PCでは矢印キーの長押しで移動できます。

3つの切り札

エネルギーは設置とライン消去で獲得。PULSEは一番下のブロックがある段から上へ3段を消去（スコア・ライン数には加算されません）。AVALANCHEは200ポイントで発動。積んだブロックが1マスずつ隙間へ崩れ落ち、そろった列を消して連鎖します。連鎖中は操作を一時停止し、連鎖数に応じた得点が入ります。PRISMは現在位置付近を優先し、置けなければ上部に I を出します。

40 LINESはスキルなし・一定速度で40ラインまでのタイムを競います。自己ベストはこのブラウザーに保存されます。ゲーム終了後に任意のニックネームで共有ランキングに登録できます。旧版の2人対戦はページ上部のリンクから遊べます。
