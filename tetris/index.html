HOW TO SHIFT

ひとつ先のプレイへ。

横一列をブロックで埋めると消去。上まで積み上がるとゲーム終了です。ARCADEでは10ラインごとにレベルと落下速度が上がります。

左右移動← → / A D右回転 / 左回転↑・X / Zソフト / ハードドロップ↓・S / Spaceホールド（1設置につき1回）C / Shiftスキル / 一時停止1 2 3 / P・Esc

スマホでは盤面下のボタンを使用。移動とソフトドロップは長押しできます。着地点の輪郭が落下位置の目印です。

3つの切り札

エネルギーは設置とライン消去で獲得。PULSEは一番下のブロックがある段から上へ3段を消去（スコア・ライン数には加算されません）。TIME SLOW中も手動の落下速度は変わりません。PRISMは現在位置付近を優先し、置けなければ上部に I を出します。

40 LINESはスキルなし・一定速度で40ラインまでのタイムを競います。記録はこのブラウザーに保存されます。旧版の2人対戦はページ上部のリンクから遊べます。
