HOW TO PLAY

覚えて、見つけて、もう1ペア。

  1. 順番にカードを2枚開きます。
  2. 同じ絵なら1ペア獲得。続けて自分の番です。
  3. 違う絵ならカードが戻り、相手の番になります。
  4. すべてのペアを見つけたとき、獲得数の多い人が勝ちです。

タップ・クリックで選択。キーボードは矢印キーで移動、Enter / Spaceで開けます。
