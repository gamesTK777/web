# セブン麻雀の自然な日本語音声

ゲーム専用のオリジナル台詞238本を、Microsoft `ja-JP-NanamiNeural` の女性音声で事前に生成したMP3です。`edge-tts 7.3.1` を使用。7人の人物像に合わせて生成時の話す速さと高さを控えめに調整しており、7種類の別人の声を収録したものではありません。ゲーム中の再生速度は常に1で、端末によるピッチ変更は加えません。

- 各人物34本：出会い・再対戦の会話9本、勝利3本、対局中の7イベント各3本、ステージ突破のご褒美台詞1本（`stageReward`）。
- 形式：MP3、24kHz、モノラル。合計7,795,152バイト。
- 長さ：1本2.232〜11.568秒、全238本で1,299.192秒（約21分39秒）。
- `manifest.mjs` は人物番号と表示台詞からファイルを選択します。
- `provenance.json` に生成設定、ファイルサイズ、SHA-256を保存しています。

MP3は必要になった台詞だけ読み込みます。開始・試聴・再生ボタンなどの操作までは音声コンテキストを作成せず、MP3も取得しません。読み込んだ音声は最大24本をメモリーに保持し、同時読込は最大2本です。再生中に外部の音声合成サービスやAPIキーは使いません。

管理者が人物名などを変更して既存の録音と一致しなくなった台詞だけ、端末の日本語読み上げを利用します。標準台詞のMP3読込が失敗した場合は別の声に切り替えず、字幕と再生し直すための案内を残します。音量・消音・場面切替・ページ非表示で古い音声を停止でき、読込が遅れても停止した台詞が後から再生されることはありません。

検証：既存231ファイルはマニフェスト一致、サイズ・ハッシュ、有限の再生時間、ffmpegによる完全デコードを確認済みで、追加時にも全231本のハッシュを照合しました。追加のご褒美台詞7本（合計414,720バイト、69.120秒）も完全デコードし、PCMへ展開して無音でないことを確認。全238本のマニフェスト対応をテストし、既存の人物別代表7本の波形確認も維持しています。
