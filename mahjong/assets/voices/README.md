# セブン麻雀のキャラクター音声

会話、対局中の声かけ、勝利時の台詞、ご褒美の案内を、話し言葉の日本語で書き直しました。245本を VOICEVOX Nemo 0.26.0 で事前に生成しています。6種類の女声を使い、キャラクター7人に合わせて速度、声の高さ、抑揚、間の取り方を生成時に調整しました。対局の開始やリーチ、勝利などで抑揚を調整しています。音声利用のクレジットは対局ページの下部にも表示します。[VOICEVOX Nemo 利用規約](https://voicevox.hiroshiba.jp/nemo/term/)

- 各人物35本。初回・続戦・再挑戦の会話9本、登録名変更時の初回挨拶1本、勝利時の台詞3本、対局中7場面の各3本、ギャラリーの案内1本。
- MP3、24 kHz、モノラル。合計6,636,892バイト。生成時のPCMは1.291～8.619秒、合計約13分28秒。
- `manifest.mjs` にキャラクター番号と字幕に対応するファイル名、`provenance.json` に音声モデル、生成設定、台詞、ファイルサイズ、SHA-256を記録しています。
- 全245本のマニフェストとファイルの対応、生成時のPCMが無音でないこと、ffmpegでの全ファイルのデコードを確認しました。

ゲームでは「声・音量の設定」から各人物を試聴できます。再生速度は常に1倍です。プレイ中は同梱のMP3を必要に応じて読み込みます。登録名を変えたキャラクターは画面上にその名前を出し、挨拶では名前を入れない専用の録音を再生します。音声を読み込めない場合は字幕と聞き直しの案内を表示します。
