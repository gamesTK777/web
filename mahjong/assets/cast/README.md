# セブン麻雀の初期キャスト素材

7人の対戦用ポートレートと、各人物の1〜3勝目に表示する記念画像です。全28枚をゲームの対応枠へ割り当てています。

内蔵画像生成で制作した、架空の成人キャラクターです。対戦用画像を参照して各勝利画像を生成し、同じ人物の顔・髪型・衣装を維持しています。登録済みの管理画像がある場合は管理画像を優先し、初期画像はそのまま保管します。

- [春野ひなた・水瀬澪・小森こはるの制作プロンプト](group-a.json)
- [橘朱音・月城紫苑・朝比奈凪・九条沙羅の制作プロンプト](group-b.json)
- [全28枚の画像寸法・容量・ハッシュ・割り当て](manifest.json)

原本と完全な生成記録は制作ワークスペースの `seven-mahjong-art/group-a` と `group-b` に保管しています。公開版はWebPに変換し、対戦画像は630×840、勝利画像は最大960×720で配信します。
